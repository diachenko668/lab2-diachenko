Лабораторная работа № 2 посвящена системе контроля версий Git и сервису GitHub.
Для работы используется репозиторий diachenko668/lab2-diachenko.
Репозиторий клонируется с GitHub в локальную рабочую папку.
Изменения файлов сохраняются отдельными коммитами с понятными сообщениями.
Новая функциональность разрабатывается в отдельной ветке feature/update.
Для проверки изменений используются тесты и самопроверка кода.
Работа выполняется индивидуально, а параллельные изменения моделируются в двух локальных копиях.
