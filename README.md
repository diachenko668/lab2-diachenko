# Лабораторная работа № 2 — системы контроля версий

Студент: Д. В. Дьяченко, группа 6В51ПИШ.
Репозиторий: https://github.com/diachenko668/lab2-diachenko

Учебный проект — консольный анализатор чисел на Python 3.10+.
Используется только стандартная библиотека; установка пакетов не требуется.

## Запуск

```bash
python3 main.py 2 4 6
python3 -m unittest discover -s tests -v
```

Программа выводит количество чисел, сумму и среднее арифметическое.

## Работа с Git

`report.txt` содержит описание работы, `shared.txt` используется для
воспроизведения конфликта слияния. Ветка `feature/update` демонстрирует
изменения и исправление замечаний; `feature/author-a` и `feature/author-b`
демонстрируют параллельную работу.

Лабораторная выполняется индивидуально: обе роли выполняет один студент
в двух локальных копиях. Самопроверка не является независимым ревью и
не позволяет одобрить собственный Pull Request на GitHub.
